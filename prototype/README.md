# WariLink フロントエンド見本

`index.html` をブラウザで開けば操作できます。外部CDNは不要、フロントだけのデモです。

- 画面: グループ・レシートOCR・商品ごとの割り勘・送金管理・受取設定。
- 操作: OCRサンプル読み込み、商品の金額の修正、負担者トグル、端数割当、送金申告、銀行明細一致の疑似再現、任意登録状態の切り替え。
- OCR、銀行API、送金、課金、永続化、実際の認証・広告表示は**実装していません**。これらを模したUIであることを常時明示しています。
- 画像を選択しても画像を外部送信しません。OCR結果はダミーデータを使用します。
- 氏名・振込先・照合コードは架空であり、支払の保証ではありません。

本番実装は `../docs/` の仕様に従い、`CLAUDE.md` に記載の順序でClaude Codeに依頼してください。
